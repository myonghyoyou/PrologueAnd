구조 A · B · C · D

A 도구형 — 문제를 고르면 요청 카드가 접수 → 분석 → 재설계 → 제품을 지나 문의 서랍이 열림.
B 도면형 — 한 장의 도면 위 노드·선. 휠·드래그 이동, Ctrl+휠 확대.
C 서사형 — 선 하나가 페이지를 관통. 매듭·정거장·삼각 플래그.
D 포스터형 — Rauno 원형. 회색 바탕 위 흰 패널을 가로로 넘김, 패널마다 문장 하나 + 도형 하나, 서체 하나. 옷은 고정.

시각 언어 3종

제품 UI풍 — Pretendard, 밝은 회색 표면 + 흰 패널, 모노스페이스 라벨, 4px 모서리.
설계도풍 — 트레이싱지, 네이비 1px 선, 코너 틱, Didone 헤드라인, 대문자 라벨.
편집물풍 — 순백, Didone + Noto Serif KR, 검정 헤어라인, 넓은 여백, 세리프 라벨.
