## 1. 로고 분석

### 1.1 구성 요소
| 요소 | 관찰 | 디자인 시스템으로의 함의 |
|---|---|---|
| 워드마크 `Prologue` | 고대비 Didone 계열 세리프(Bodoni/Didot 류). 헤어라인과 굵은 수직획의 대비가 큼 | 클래식·편집물·신뢰의 인상. 헤드라인 서체 선택의 기준점 |
| 앰퍼샌드 `&` | 로고의 유일한 "사건". 하단 볼이 네이비→스틸블루 그라데이션 위에 **면분할(facet) 선**으로 채워짐. 끝에 작은 삼각형 플래그 | "구조화된 조각", "설계도", "연결"의 메타포. 브랜드의 유일한 장식 요소 |
| 수평선 2개 | `&` 양옆의 얇은 hairline rule | 섹션 구분선·표 괘선으로 확장 가능 |
| 심볼 `P&` | 모노그램 리거처 | 파비콘·프로필·카드 뱃지·소형 표기 |

### 1.2 색
| 이름 | 근사값 | 출처 |
|---|---|---|
| Ink | `#111318` | 워드마크 검정(순흑이 아닌 아주 어두운 남색 기미) |
| Navy | `#2B3160` | `&` 그라데이션의 짙은 쪽 |
| Steel | `#7A8AA6` | `&` 그라데이션의 밝은 쪽 |
| Paper | `#FFFFFF` | 기본 배경 |

### 1.3 성격 요약
"출판물의 격조 + 한 점의 구조적 액센트". 스타트업 SaaS 톤(둥근 산세리프, 비비드 그라데이션, 글래스 효과)과는 거리가 멀고, 편집·건축·컨설팅 톤에 가깝다.
브랜드명 자체의 의미(Prologue **And** = 시작, 그리고 이어짐 / Prologue **End** = 끝까지. 같은 발음 — "처음과 끝을 함께한다", `01` §1)도 "고객의 다음 장을 함께 열고 끝까지 간다"는 서사로 쓸 수 있다.

## 3. 후보 5안

### 1안. 에디토리얼 미니멀 — "격조 있는 제안서"
- **개념**: 로고의 Didone 성격을 사이트 전체로 확장. 잘 만든 컨설팅 제안서/매거진처럼 읽히는 사이트
- **팔레트**: Paper `#FFFFFF` / Ink `#111318` / Navy `#2B3160` / Steel `#7A8AA6` / Mist `#EEF0F4`
- **타이포**: 디스플레이 = Didone 계열 라틴(예: Bodoni Moda) + 한글 세리프(Noto Serif KR) / 본문 = Pretendard
- **레이아웃**: 좁은 본문 컬럼(65~72자), 로고의 hairline rule을 섹션 구분선으로 재사용, 카드 최소화. 좌측 정렬
- **로고 연결**: 워드마크 그대로. `&`는 섹션 전환 장식으로 1회만
- **Hero 구상**: 브랜드 문장을 대형 세리프로, 그 아래 서브 문장과 CTA. 이미지 없음
- **장점**: 가장 안전하고 로고와 가장 잘 맞음. B2B 신뢰감 최상. 구현 비용 낮음
- **리스크**: "디자인 에이전시"처럼 보여 제품 구현력이 약하게 전달될 수 있음. 스크린샷 삽입 시 톤 충돌 주의
- **적합 프로젝트**: 4개 모두 무난

### 2안. 블루프린트 — "설계도로 말하는 사이트"
- **개념**: `&` 안의 facet 선을 디자인 시스템으로 승격. 얇은 네이비 선으로 그린 **Workflow 다이어그램이 Hero이자 주 콘텐츠**. 스크린샷은 다이어그램의 보조
- **팔레트**: Tracing `#F7F8FA`(종이가 아닌 트레이싱지 느낌) / Navy `#2B3160` / Line `#7A8AA6` / Ink `#111318` / Flag `#3E4A8C`(삼각 플래그·완료 상태 전용)
- **타이포**: 헤드라인 = 로고 Didone + Noto Serif KR / 본문·다이어그램 라벨 = Pretendard
- **레이아웃**: Hero = "복잡한 업무(엉킨 선) → 단순한 제품(정리된 선)"이 한 장면으로 그려진 SVG + 브랜드 문장. Case Study의 Before/After도 동일 선 문법으로 통일
- **로고 연결**: 삼각 플래그를 CTA·완료 상태 아이콘으로, facet 선을 다이어그램 선 굵기·색으로 계승
- **장점**: 포지셔닝("Problem → Workflow → UX")을 시각 언어 자체로 증명. 경쟁 포트폴리오와 확실히 구분. NDA로 화면을 못 쓰는 프로젝트도 다이어그램으로 커버
- **리스크**: 다이어그램 제작 공수 큼(프로젝트당 Before/After 최소 2개). 선이 많아지면 어수선 → 선 굵기 2단계, 색 2단계로 제한하는 절제 규칙 필요
- **적합 프로젝트**: Por favor Harry·Daeryun Learning Hub 최적, 병원·Commerce도 흐름도로 표현 가능

### 3안. 딥 네이비 프로덕트 — "야간 작업실"
- **개념**: 네이비 다크 배경 위에 화이트 로고(white 변형)와 제품 화면이 떠 있는 구성. 제품 구현력을 전면에
- **팔레트**: Base `#161A33` / Surface `#1F2447` / Text `#F3F4F8` / Steel `#7A8AA6` / Highlight `#A9B4D0`
- **타이포**: 헤드라인 = Didone 화이트 / 본문 = Pretendard
- **레이아웃**: 넓은 Hero에 대형 스크린샷 1장, 섹션마다 제품 화면이 주인공
- **로고 연결**: `[color]P& white` 변형이 가장 아름답게 보이는 조건
- **장점**: "만들 수 있는 사람"이 즉시 전달됨
- **리스크**: 다크 SaaS 톤은 가장 포화된 유행. 주 고객(병원·제조·건설 담당자, 고령 사용자)의 가독성·인쇄 공유에 불리. 스크린샷 공개 범위 미확정 상태에서 콘텐츠 부족 위험
- **적합 프로젝트**: Custom Commerce 최적, 병원 UI/UX는 화면 공개 여부에 좌우

### 4안. 스위스 구조주의 — "정보 위계가 곧 디자인"
- **개념**: 엄격한 12컬럼 그리드, 좌측 정렬, 큰 크기 대비의 산세리프. 장식 없이 구조만으로 "단순화"를 보여줌. 세리프는 로고에만 남김
- **팔레트**: Paper `#FFFFFF` / Ink `#111318` / Navy `#2B3160` 단일 액센트 / Rule `#D9DCE3`
- **타이포**: 전체 Pretendard(디스플레이 700 초대형 ↔ 본문 400 소형의 극단적 크기 대비). 로고만 Didone
- **레이아웃**: 순서가 실제로 있는 콘텐츠(How Prologue& Works 5단계, Case Study 10단계)에만 번호 마커. 나머지는 그리드 정렬로 위계 표현
- **로고 연결**: 워드마크만. `&` 요소는 확장하지 않음
- **장점**: "불필요한 것을 제거한다"는 메시지를 형식이 증명. 모바일 대응·구현 가장 쉬움
- **리스크**: 로고의 세리프 개성과 사이트 산세리프 사이의 단절감. "평범한 기업 사이트"로 보일 수 있음
- **적합 프로젝트**: 병원 UI/UX(정보 위계 개선 사례)와 잘 맞음

### 5안. 종이에서 제품으로 — "전환 내러티브"
- **개념**: Before(종이·엑셀·메신저)는 종이 질감·손글씨 느낌, After(웹 제품)는 흰색·네이비로 대비. 스크롤에 따라 Before가 After로 정리되는 장면 전환
- **팔레트**: Before Paper `#EDE7DA` + Ink `#3A3630` / After Paper `#FFFFFF` + Navy `#2B3160`
- **타이포**: Before = 세리프 / After = Pretendard. 전환 자체를 타이포로 표현
- **레이아웃**: Case Study 페이지에서 가장 강력. 홈은 Hero 1회 전환 후 After 톤 유지
- **로고 연결**: After 영역에서만 컬러 로고, Before 영역은 mono
- **장점**: "Digitization ≠ Copy" 메시지와 완벽히 일치. 기억에 남음
- **리스크**: 크림/종이 톤은 AI 생성 디자인의 대표 클리셰라 절제 못 하면 역효과. 스크롤 모션 구현·성능 부담 최대. 병원 UI/UX·Custom Commerce는 "종이 → 웹" 서사가 아니라 맞지 않음
- **적합 프로젝트**: Daeryun Learning Hub 최적, Por favor Harry 가능
