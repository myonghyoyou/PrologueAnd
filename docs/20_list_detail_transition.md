## 구현
- **크로스도큐먼트 View Transitions**(`@view-transition { navigation: auto }`): iframe 안 페이지 이동을 그대로 두고 동작(Chrome 126+ · Safari 18.2+ 확인, Firefox는 자동으로 전환 없음).
- 공유 요소: 클릭한 행에만 `.vt` → `.h2 { view-transition-name: pj-title }`, 상세의 `.case-head .h1`에 같은 이름. 그룹 350ms, 루트는 150ms 아웃 / 250ms 인 + 8px 상승.
- 돌아올 때: `sessionStorage('vt-slug')`로 행을 찾아 `pagereveal`에서 이름을 붙이고 `viewTransition.finished` 후 제거 → 제목이 제자리로 내려옴.
- 시트(embed) 안에서는 번호 레일을 표시(원래 <1024px에서는 숨김)하고 도착 후 그려짐. `prefers-reduced-motion`이면 전환·그리기 없음.
- 시트 헤더 제목(`Prologue & {제목}`)은 부모 문서라 iframe 경계를 넘는 공유 요소는 불가 → 목적지는 상세 상단 H1.
