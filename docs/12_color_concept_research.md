# 컬러·컨셉 리서치 — D2 변형 시안을 위한 조사 보고

| 작성일 | 2026-09-16 |
|---|---|
| 목적 | D2 합본형 템플릿을 고정한 채 **컬러셋과 컨셉만 다른 변형**을 만들기 위해, 최근 유행하는 색·컨셉과 오래 사랑받아온 색·컨셉을 조사하고 D2에 적용 가능한 후보로 정리한다 |

| 방법 | 색 예측 기관(Pantone·WGSN/Coloro·NCS 등) 발표, 2026 웹 컬러/컨셉 트렌드 글 8건, 트렌드 사후 검증 글, 국내 트렌드 글 3건, 앞서 직접 검토한 9개 사이트(`09`)의 팔레트 재분석 |

## 1. 결론 먼저

1. **2026의 큰 흐름은 "차분함"과 "따뜻함"이다.** Pantone은 사상 처음으로 흰색(Cloud Dancer)을 올해의 색으로 뽑았고, 5대 기관의 선택이 화이트·브라운·틸·오렌지로 갈린다 — "극단의 경계에서 찾은 균형". 웹에서는 뼈·모래·차콜 같은 **따뜻한 무채색(Quiet Luxury)** 이 가장 널리 채택됐다.
2. **스테디는 세 가지 계보.** ① 흑백 모노크롬 + 액센트 1색(스위스·바우하우스 계보, Rauno의 회색+노랑도 여기) ② 네이비 + 크림(+골드)(금융·기업 신뢰) ③ 다크 + 네온 단일 액센트(Linear·Raycast, 2022~ 포화)
3. **컨셉은 "편집물·미니멀·벤토·다크"가 살아남았고, 키네틱 타이포·글래스·3D는 시연용에 그쳤다**(사후 검증). 벤토가 포화되자 반동으로 **소프트 브루탈리즘·안티그리드**가 차별화 수단으로 떠오른다.
4. **D2는 이미 Rauno 계보(회색 바탕 + 흰 패널 + 밝은 액센트 도형)에 있다.** 따라서 변형은 "액센트 도형 색 + 바탕 온도"를 바꾸는 것으로 충분히 다른 인상이 나온다. 구조를 흔들 필요 없다.
5. **제안 후보 7개** 중 실제 시안 제작은 4~5개를 권한다(§6).

### 4.2 스테디 컨셉
- **스위스/국제 타이포그래피**: 그리드·산세리프·비대칭·여백 — 60년 넘게 유효
- **미니멀**: 요소를 빼는 것이 곧 브랜드 — 다만 2026엔 "성격 있는 미니멀"이어야 함
- **포스터 구성**: 문장 하나 + 도형 하나 — Rauno·바우하우스 포스터·일본 그래픽. **D2의 본질**
- **모노크롬 타이포 히어로**: 큰 글자만으로 첫인상 — 검정/흰

### 4.3 D2에 컨셉을 얹는 방법
D2 구조는 이미 "포스터 + 스위스 + 미니멀"이라 컨셉은 **색의 온도와 액센트의 성격**으로 표현된다.
| 컨셉 | 색으로 번역하면 |
|---|---|
| 차분한 신뢰(2026 주류) | 따뜻한 흰 바탕 + 스톤/모래 도형 + 따뜻한 검정 |
| 대담한 에너지(2026 반대편) | 밝은 회색 바탕 + 노랑/살구 도형 + 순검정 |
| 웰니스·자연 | 연한 회녹 바탕 + 세이지 도형 + 짙은 초록 |
| 프리미엄 다크 | 거의 검정 바탕 + 네이비 도형 + 흰 글자 |
| 브랜드 직결 | 회색 바탕 + 하늘색 도형 + 로고 네이비 (현재) |

## 5. D2에 적용할 때의 제약 (변형 공통)

1. 색은 5개: **바탕 / 패널 / 글자 / 주도형(글자를 덮음, 반드시 밝음) / 보조도형(글자와 안 겹침, 어두워도 됨)**
2. 글자 대비: 패널 위 본문 4.5:1 이상, 헤드라인은 주도형 위에서도 3:1 이상(큰 글자 기준)
3. 로고는 흑/백 변형만 있으므로 **검정 로고가 읽히는 밝은 바탕**이거나, 다크에서는 흰 로고
4. 크림 바탕 + 테라코타 액센트, 검정 바탕 + 형광 1색 — AI 생성 클리셰 2종은 그대로 쓰지 않는다(변주는 가능)
5. 12번 문의 패널(현재 네이비 반전)은 팔레트마다 "반전 패널" 색을 따로 정한다
