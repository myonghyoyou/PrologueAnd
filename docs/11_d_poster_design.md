## 1. D의 문법 (변하지 않는 규칙)

1. **패널 하나 = 문장 하나 + 도형 하나.** 단어 12개 이하. 설명이 더 필요하면 패널을 하나 더 만든다.
2. **서체 하나.** Pretendard 500, 자간 -.035em, 행간 1.02. 라벨·보조문만 작게, 굵기 변화 없음. 로고 워드마크만 세리프.
3. **색 다섯.** 회색 바탕 `#ECEDF0` / 흰 패널 / 검정 글자 `#111318` / 네이비 `#2B3160` / 하늘색 `#7DB6F2`. 그라데이션·그림자·투명도 없음. **글자를 덮는 도형은 하늘색만** — 네이비 위의 검정 글자는 읽히지 않는다.
4. **도형은 글자를 덮는다.** 도형이 글자를 피해 가지 않는다. 글자가 도형 위에 온다.
5. **가로로 넘긴다.** 휠·키보드·드래그. 관성 있음, 스냅 없음. 다음 패널이 오른쪽에 살짝 보인다.
6. **화면 요소는 넷.** 로고(좌상), Projects·문의(우상), 필름 스트립(상단 중앙), + 커서. 그 외 고정 요소 없음. 커서 라벨은 `data-view`를 선언한 요소(패널·목록 항목·문의)에서만 뜨고, 닫기 같은 일반 버튼에서는 십자만 회전한다.
7. 인터랙션은 `09` §8의 5종 안에서: 가로 관성 이동 + 진행 스트립(1), + 커서(2), 로드 시 패널 상승(3), 상세 패널·서랍 슬라이드(4), (선택) 이동 속도 연동 축소(5). 핀 고정은 D에 없음 — 패널 자체가 정지 화면이므로 불필요.

## 3. Case Study — 읽기용 상세 패널 (2026-09-16 변경)

처음엔 Case Study도 6장 패널 스트립으로 만들었으나, 사용자 피드백 "대시보드(포스터) 디자인을 상세에도 쓰면 피로하다"에 따라 **읽기용 상세 패널**로 바꿨다. 포스터는 첫인상과 탐색용, 상세는 읽기용으로 역할을 나눈다.

- 프로젝트 패널 또는 목록 항목 클릭 → **화면 가운데 시트**(폭 56rem, 상하 4vh 여백)가 살짝 확대되며 페이드인(350ms), 닫힐 때 반대로. 배경 어둡게, 닫기·Esc·배경 클릭으로 닫힘 (2026-09-16: 오른쪽 슬라이드에서 변경)
- 패널 구성: 상단에 회색 띠 + 그 프로젝트의 선 도형(포스터와 같은 도형으로 연결감 유지) → 제목(크게) · 태그 → 10단계 본문을 왼쪽 라벨 / 오른쪽 본문 2열로 차분하게 → 하단 "이 프로젝트를 보고 문의하기"(서랍 열림, 프로젝트 첨부) → Built with
- 본문은 `shared.js`의 `P.caseHTML()`(Notion 블록에 대응)을 그대로 사용, 스타일만 D 문법(Pretendard·검정 선·하늘색 강조)
- 모바일: 전체 화면 패널, 2열 → 1열

## 9. D 변형 3종 비교 (2026-09-16)

A·B·C 시안 파일은 제거했다(git 이력에 남음). D 하나를 세 버전으로 나눠 비교한다. 파일은 하나(`d-poster.html?v=1|2|3`), 허브 `index.html`에서 전환.

| 버전 | 정보 구조 | 패널 형태 | 장수 | 비교 목적 |
|---|---|---|---|---|
| **D1 분리형** | 문제 4장 + 대표 프로젝트 4장 | 회색 바탕 위 흰 카드, 다음 카드가 옆에 보임 | 12 | 기준 |
