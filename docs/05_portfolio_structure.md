# 7. 문의폼 구조

문의 단계부터 고객이 문제를 구조화하도록 만든다.

질문 예시:
- 현재 어떤 업무를 하고 있나요?
- 지금 어떤 도구를 사용하고 있나요?
- 가장 불편한 부분은 무엇인가요?
- 이 업무를 몇 명이 사용하나요?
- 얼마나 자주 반복되나요?
- 기존 시스템 개선인가요, 신규 구축인가요?
- 원하는 결과는 무엇인가요?
- 희망 일정은 언제인가요?
- 예산 범위가 있다면 어느 정도인가요?

목표:
상담 전 고객 문제의 60~70%를 파악한다.
