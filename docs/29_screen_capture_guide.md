## 2. 캡처 규격 (다섯 장 모두 같게)

## 5. 넣는 방법 (코드)
`v3/cases.js`에서 각 화면을 바꾼다. 상세는 `type:'img'`도 같은 자리·같은 크기 규칙으로 그린다(핫스팟·와이프 포함).
```js
hero:   { type: 'img', src: '../v2/img/pfh/queue.png',  cap: '심사 대기열: 요청 6건이 한 화면에' },
s06.screen: { type: 'img', src: '../v2/img/pfh/form.png', cap: '요청 양식: 요청하는 사람이 필수 항목을 채워 보냄' },
s07.before: { type: 'img', src: '../v2/img/pfh/before.png', cap: 'Before: 메신저·메일·엑셀·메모에 흩어진 요청' },
s07.after:  { type: 'img', src: '../v2/img/pfh/queue.png',  cap: 'After: 심사 대기열 하나' },
```
01·02에 현황판·확인 화면을 쓰려면 `s01.pic`, `s02.pic` 필드를 추가한다(다음 작업).
