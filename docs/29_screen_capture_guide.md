## 2. 캡처 규격 (다섯 장 모두 같게)

| 항목 | 값 |
|---|---|
| 브라우저 창 안쪽 크기 | **1280 × 800** (DevTools → Toggle device toolbar → Responsive 1280×800, DPR 2) |
| 저장 배율 | 2배 → **2560 × 1600 PNG** (`Capture screenshot` 또는 `Capture full size screenshot` — 스크롤 없는 상태에서) |
| 포함하지 않는 것 | 브라우저 탭·주소창, 마우스 커서, 툴팁, 포커스 링, 개발자 도구, OS 알림 |
| 테마·줌 | 라이트, 100%. 폰트 렌더링이 흐리면 DPR 2 확인 |
| 날짜 | 화면의 오늘 날짜는 **2026-09-16 (수)** 로 통일(시안 전체가 이 날짜). 실제 앱에서 바꿀 수 없으면 캡처 후 그 부분만 가림 없이 두되, 상대 날짜(“오늘”)가 어긋나지 않게 |
| 로그인 사용자 | 담당자 계정 표시 이름은 `담당자`(아래 가명 세트의 "하늘 담당") |
| 빈 상태·로딩 | 스켈레톤·스피너가 남지 않게 데이터가 다 그려진 뒤 |
| 파일명 | 위 표 그대로. 경로 `design/mockups/v2/img/pfh/` |

## 5. 넣는 방법 (코드)
`v3/cases.js`에서 각 화면을 바꾼다. 상세는 `type:'img'`도 같은 자리·같은 크기 규칙으로 그린다(핫스팟·와이프 포함).
```js
hero:   { type: 'img', src: '../v2/img/pfh/queue.png',  cap: '심사 대기열: 요청 6건이 한 화면에' },
s06.screen: { type: 'img', src: '../v2/img/pfh/form.png', cap: '요청 양식: 요청하는 사람이 필수 항목을 채워 보냄' },
s07.before: { type: 'img', src: '../v2/img/pfh/before.png', cap: 'Before: 메신저·메일·엑셀·메모에 흩어진 요청' },
s07.after:  { type: 'img', src: '../v2/img/pfh/queue.png',  cap: 'After: 심사 대기열 하나' },
```
01·02에 현황판·확인 화면을 쓰려면 `s01.pic`, `s02.pic` 필드를 추가한다(다음 작업).
