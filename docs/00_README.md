# Prologue& 포트폴리오 PRD 준비 자료

이 폴더는 개인 브랜드 **`Prologue&`**의 포트폴리오 및 서비스 마케팅 사이트 PRD 작성에 필요한 배경 자료를 주제별로 분리한 문서 모음이다.

`Prologue&`은 단순한 개인 개발자 포트폴리오 이름이 아니라, 앞으로 외부에 공개할 **개인 브랜드의 최상위 이름**으로 사용한다.

포트폴리오와 서비스는 `Prologue&` 아래에서 운영하며, 핵심 브랜드 메시지는 다음과 같다.

> **Prologue& — 복잡한 업무를 단순한 제품으로 바꿉니다.**

필요할 경우 포트폴리오/서비스 영역은 `Prologue& Studio`, `Prologue& Work` 등 하위 명칭을 사용할 수 있지만, 브랜드의 중심은 항상 **Prologue&**이다.

---

## 프로젝트의 목적

단순 개발자 포트폴리오를 만드는 것이 아니다.

> **복잡한 업무를 더 좋은 Workflow와 UX로 재설계하고, 실제 제품까지 구현할 수 있는 B2B Product Engineer로 포지셔닝하며, 외주/컨설팅 문의와 장기적인 SaaS 문제 발굴까지 연결되는 Prologue& 브랜드 허브를 만든다.**

## PRD 작성 시 가장 중요한 전제

1. 브랜드의 최상위 이름은 **`Prologue&`**이다.
2. 이 사이트의 주 고객은 개발자가 아니라 **업무 시스템 개선, MVP 개발, 사내 도구 구축이 필요한 잠재 고객**이다.
3. 기술 스택보다 **Problem → Workflow → UX → Product → Impact**를 우선한다.
4. 포트폴리오의 핵심 전환 목표는 단순 조회가 아니라 **프로젝트 문의**다.
5. 장기적으로는 외주 문의에서 반복되는 문제를 수집해 **Vertical SaaS 아이디어로 발전시키는 것**까지 고려한다.
6. 회사/병원 등 실제 업무 프로젝트는 **공개 권한·NDA·IP·개인정보**를 우선 검토하고, 필요 시 화면을 익명화하거나 Mockup으로 재구성한다.
